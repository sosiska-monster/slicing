# С чего начать

Мы строим локальный редакторский процесс **VOD → отбор → JSON-план → титры → вертикальный MP4**.
Это не сервис автоматического клиппинга по оценке модели. ИИ принимает редакторские решения по содержанию и контрольным кадрам; готовые решения и метки сохраняются, повторный рендер полностью локален.

Порядок чтения:

1. [Текущее состояние](CURRENT_STATE.md) — что закончено и какие ограничения остались.
2. [История](HISTORY.md) — через какие пилоты и ошибки прошли.
3. [Архитектура](ARCHITECTURE.md) — команды, координаты и компоненты.
4. [Локальные данные](LOCAL_DATA.md) — что отсутствует в Git и как найти оригиналы.
5. `project_context/manifest.json` — соответствие упакованных файлов локальным оригиналам, их SHA-256.
6. Корневой README — установка и старые примеры CLI; его 480p-подготовка исторически предшествует HQ-процессу.

В project_context включены существующий каталог, расшифровка, индексы, планы, вычитка и отчёты выбранных этапов. Это снимки, не новая миграция данных и не гарантия готовности к публикации. Отчёты прошлых запусков не являются тестами, выполненными при создании репозитория.

Пример запроса следующей ИИ:

> Прочитай AGENTS.md и docs/START_HERE.md. Объясни актуальное состояние slicing и отличие BATCH_18b_v2 от старого мастера. Перед изменениями найди нужный план и проверь локальное наличие исходника. Не запускай пакетный рендер и не публикуй ролики без отдельной задачи.

Содержимое документации основано на сохранённых артефактах и истории задач. Старые эксперименты не представлены фиктивными Git-коммитами: первый снимок репозитория фиксирует уже существующий код.
