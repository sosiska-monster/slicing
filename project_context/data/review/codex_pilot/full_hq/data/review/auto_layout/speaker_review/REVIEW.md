## Разметка

В `framing.regions` у области лица добавляется `speaker` с именем. `box` или `track` указывают лицо целиком в пикселях исходника. `viewport` ограничивает доступный для кропа участок камеры. Если размечен один говорящий, он занимает главный план весь отрезок.

При нескольких участниках `framing.speaker_turns` последовательно покрывает исходный отрезок. У записи есть `start_ms`, `end_ms` и `speaker`. Поле `reaction` указывает участника для меньшего окна. `hold: true` сохраняет предыдущего говорящего и его окно на коротком подтверждении или перебивке. Такие записи объединяются с предыдущим планом.

Кроп рассчитывается по пропорциям выходного кадра. Цель центра лица составляет X 50% и Y 40%, начальная зона составляет X 45–55% и Y 35–45%. Лицо проверяется целиком и получает запас вокруг головы в пределах `viewport`. Python сначала ищет положение в начальной зоне, затем ближайший безопасный вариант, если зоны UI или титров не дают сохранить её. Для реакции проверяется также размер проекции лица и отсутствие пересечения с главным лицом и титрами. Манифест сохраняет говорящего, центры по меткам и результат проверки начальной зоны.

Исходные сегменты используются для звука и привязки меток. Смены говорящего делят только видеоряд. Событие ASS, пересекающее новую склейку, сохраняет текст и подсветку по обе стороны склейки.

## Проверки

- Оба MP4 и обзор полностью декодированы. FFprobe подтвердил 1080 × 1920, 30 кадр/с, H.264 и AAC. Обзор длится 13,50 с, проверен порядок всех 404 кадров.
- На 259 кадрах с титрами проверены фактические границы ASS с обводкой. Пересечений с лицами, окном реакции и зонами UI не найдено. Профили Krumzi дают расчётную оценку.
- Для обоих клипов AAC совпал побайтно со звуком, закодированным напрямую из одного непрерывного исходного интервала. Временная индексированная копия HQ проверена на 1 458 пакетах с совпадением PTS, DTS и содержимого.
- Прошли 12 тестов, включая смену главной камеры, сохранение второго лица и удержание кадра на перебивке. Тест PostgreSQL пропущен без отдельной тестовой базы. Diff построен относительно снимка перед правкой и проверен командой `git apply --reverse --check`.

В этом каталоге сохранены планы, метки, вычитка, измерения и контрольные кадры. MP4, ASS и манифесты лежат в штатных каталогах `AUTO_SPEAKER_*`.
