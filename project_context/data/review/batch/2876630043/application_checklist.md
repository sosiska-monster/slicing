# Чек-лист конкурсной заявки

Условия перенесены из присланных правил.

- [ ] Публикация датирована с 10.07. Возраст ролика на момент заявки до 14 дней.
- [ ] Использовано максимум два рабочих аккаунта.
- [ ] По ролику оформляется одна выплата.
- [ ] Статистика органическая. Просмотры считаются по одной публикации.
- [ ] В тексте публикации есть #evelone и twitch: evelone2004.
- [ ] В мобильном предпросмотре видны титры, важные лица, заголовок, ответ и сумма. Видимые рекламные баннеры закрыты.
- [ ] Спорные условия сверены с /rules.

| Просмотры одной публикации | Выплата |
| ---: | ---: |
| 100 000 | $15 |
| 250 000 | $25 |
| 500 000 | $50 |
| 1 000 000 | $100 |

Дата, рабочий аккаунт, ссылка и статистика заполняются по факту публикации в записи нужной площадки в индексе.
