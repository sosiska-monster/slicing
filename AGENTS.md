# Контекст для следующей ИИ

Начните с `docs/START_HERE.md`, затем `docs/CURRENT_STATE.md` и `docs/HISTORY.md`.
Снимок создан 2026-11-14. Это первый Git-базис существующего проекта, а не начало его разработки.

- Цель: самостоятельные вертикальные истории из Twitch VOD, главный герой Evelone. Редактор выбирает содержание; Python/Whisper/FFmpeg выполняют локальные технические операции.
- Используйте существующий `python -m slicing --edit-plan ... --clip ...`. Ручные планы v1 crop/place должны сохранять совместимость. Skill `slicing-editor` запускается явно пользователем.
- `crop` — координаты исходника; `place` — сетка 720×1280, даже при экспорте 1080×1920. Не смешивайте шкалы и старый 480p с HQ.
- HQ-рендер запускается с рабочим корнем `data/review/codex_pilot/full_hq/`, а не из корня репозитория со старым VOD.
- Сохраняйте звук и готовые метки при правках только картинки. Сдвиг −42,7 мс нужен только при прямом переносе старых 480p-меток. HQ-метки не сдвигать.
- Не перезаписывайте старые клипы: новые версии получают отдельный ID и каталог. Рендер отказывается писать в существующий каталог.
- В текущей партии целые фразы титров, максимум две строки, фиксированное положение. Пословная подсветка поддерживается, но не является текущим редакторским стандартом.
- Не считайте центр объекта доказательством его сохранности: проверяйте все края, движение, реальные границы текста с обводкой и отдельные UI-профили.
- Krumzi — расчётные оценки, не мобильный просмотр. Проверка PCM/ASR — не слуховая оценка. Отчёт должен честно разделять выполненные проверки.
- Исходники, PostgreSQL, расшифровка, прежние клипы и результаты экспериментов сохраняются. Удаление данных, новые зависимости, публикация и подача заявки требуют отдельной задачи.
- Не запускайте всю партию ради точечной правки. Сначала проверяйте индекс и хеши, затем следующий незавершённый этап.
- В Git нет видео, аудио, базы, секретов и полного каталога data. `project_context/` — выборочные текстовые снимки для понимания; пути из них относятся к локальному рабочему набору и не гарантируют наличие файлов в клоне.
- Актуальный монолог: BATCH_18b_v2. Основной batch-индекс ещё указывает старый BATCH_18b; подробности в CURRENT_STATE.

Проверки: `python -B -m unittest discover -s tests -v`. PostgreSQL-тест требует отдельную тестовую БД. Без неё пропуск нормален; не используйте рабочую БД.
